# Ocean Rage

Ocean Rage é um mod de desastre natural para Minecraft Java.

O mod adiciona um evento de tsunami. Ao usar o comando perto de uma praia, rio ou oceano, a água recua e depois uma onda gigante vem do mar em direção à terra.

## Versão

```txt
Minecraft Java: 1.20.1
Loader: Forge
Mod: Ocean Rage
```

## Comandos

```txt
/oceanrage start
/oceanrage start small
/oceanrage start medium
/oceanrage start giant

/oceanrage toxic
/oceanrage toxic small
/oceanrage toxic medium
/oceanrage toxic giant

/oceanrage stop
/oceanrage status
```

## Como usar

Fique perto de água e use:

```txt
/oceanrage start giant
```

Para a versão venenosa:

```txt
/oceanrage toxic giant
```

Para parar tudo:

```txt
/oceanrage stop
```

## Build

O `.jar` é gerado pelo GitHub Actions em:

```txt
Actions > Build Mod > ocean-rage-jar
```
