# Ocean Rage

Minecraft Forge 1.20.1 disaster mod.

Ocean Rage adds a tsunami event controlled by commands. The wave starts far in front of the player, the water recedes, then a huge wall of water advances, pushes entities, deals damage and can apply toxic effects.

## Commands

```txt
/oceanrage start
/oceanrage start small
/oceanrage start medium
/oceanrage start giant
/oceanrage toxic
/oceanrage toxic small
/oceanrage toxic medium
/oceanrage toxic giant
/oceanrage stop
/oceanrage status
```

## Build

The jar is generated by GitHub Actions.

Go to:

```txt
Actions > Build Mod > artifact ocean-rage-jar
```

The final file will be inside:

```txt
build/libs/ocean-rage-1.0.0.jar
```
